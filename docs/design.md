# Smart Clipboard Manager - 跨平台智能剪贴板管理器

## Context

剪贴板是日常使用最频繁的系统能力之一，但系统原生剪贴板通常只保留最近一条内容，缺少历史检索、分类组织、批量操作、跨设备同步和安全保护能力。本项目旨在构建一个轻量、智能、跨平台的剪贴板管理器，围绕以下真实场景提供完整解决方案：

- 复制内容被覆盖后无法找回
- 频繁复用相同文本、代码片段、地址、回复模板
- 无法按内容类型、标签或拼音快速检索历史记录
- 多台设备之间缺乏安全、可控的同步机制
- 剪贴板中存在密码、Token、连接串等敏感信息，需要额外保护
- 桌面工具需要兼顾性能、后台常驻能力与原生系统集成体验

当前代码已从最初的 MVP 逐步演进为包含历史管理、智能分类、图片与标签、模板系统、局域网同步、WebDAV 云同步、冲突处理、应用锁、生物识别、数据库加密、托管更新和拼音模糊搜索的完整桌面应用。本文档基于当前仓库实现，更新系统设计、功能边界、分阶段实施成果和后续路线图。

## 一、当前产品能力概览

### 1. 剪贴板历史管理

- **后台自动捕获**：通过 Rust 后端持续监听系统剪贴板变化
- **多类型支持**：支持纯文本、结构化文本、图片等内容
- **去重与复用统计**：相同内容避免重复入库，并累计使用次数
- **历史容量控制**：支持最大保留条数、保留天数和自动清理
- **收藏能力**：常用内容可置顶/收藏，避免被清理
- **时间线浏览**：前端按时间组织展示历史记录
- **批量操作**：支持多选模式下的批量删除、批量收藏/取消收藏、批量打标签、合并复制，以及全选/反选/清空选择
- **虚拟滚动**：大列表场景下仅渲染可视区域条目，保障滚动流畅性

### 2. 智能识别与内容增强

- **内容分类**：自动识别 URL、Email、代码、JSON、文件路径、颜色、电话、地址、图片、普通文本等
- **敏感信息检测**：检测密码、API Key、Token、JWT、连接串等高风险内容
- **内容转换**：支持大小写处理、URL 编解码、JSON 格式化等快捷操作
- **标签系统**：支持自定义标签、标签筛选和批量打标签
- **模板系统**：支持可复用文本模板与 `{{placeholder}}` 参数填充
- **使用统计**：支持分类占比、使用频率、每日活动等统计视图

### 3. 搜索与检索

- **SQLite FTS5 全文检索**：支持大规模历史记录的快速查询
- **拼音模糊搜索**：支持中文内容按原文、全拼、首字母搜索
- **短查询兜底**：对短拼音输入提供 LIKE 回退策略，提升命中率
- **分类过滤**：按内容类型快速过滤结果
- **标签辅助检索**：结合标签实现更细粒度内容组织

### 4. 同步能力

- **局域网同步（LAN Sync）**：基于 mDNS 发现设备、WebSocket 建立连接、端到端加密传输
- **云端同步（WebDAV）**：支持通过 WebDAV 服务进行跨网络剪贴板同步
- **设备注册与轮询**：支持设备登记、增量同步、可配置轮询
- **冲突处理**：支持高级同步冲突识别、策略化解决与手动差异处理 UI
- **同步范围控制**：支持图片、敏感内容是否参与同步等配置

### 5. 安全与隐私

- **应用锁**：支持密码锁、自动锁定、手动锁定（设置面板按钮 + 托盘菜单）
- **启动时锁定检查**：应用启动时自动检测锁定状态，锁定时直接展示解锁界面
- **受保护唤起链路**：托盘、热键、窗口唤起前会检查锁定状态，锁定时拦截并引导至解锁界面
- **命令级访问保护**：敏感 Tauri IPC 命令在锁定状态下通过 `require_unlocked()` 守卫拒绝访问
- **锁定时缓存清理**：进入锁定态时主动清空前端敏感缓存数据
- **生物识别集成**：macOS 支持 Touch ID，Windows 支持 Windows Hello，Linux 回退密码解锁
- **本地数据库加密**：支持 AES-256-GCM 静态加密，密钥存储在系统凭据/钥匙串中
- **密码安全存储**：应用锁密码使用 Argon2 哈希，不保存明文

### 6. 桌面集成与运维能力

- **全局快捷键**：`Cmd/Ctrl + Shift + V` 唤起主面板
- **系统托盘常驻**：支持后台运行、托盘控制
- **开机自启动**：支持系统登录后自动启动
- **主题与语言**：支持系统/浅色/深色模式，支持中英文界面
- **托管更新器**：支持更新检查、镜像源、下载进度、签名校验和安装交接

### 7. 插件扩展

- **插件发现**：自动扫描 `plugins/` 目录，校验 manifest 格式与字段完整性
- **启用/禁用管理**：在设置面板中查看插件元数据、切换启用状态，持久化保存
- **转换动作接入**：插件提供的转换动作直接出现在 Transform 菜单中
- **受信执行链路**：通过独立的后端插件命令路径执行，内置 handler 安全绑定
- **示例插件**：随仓库附带 `markdown-tools` 插件，演示 manifest 加载、registry 调度与端到端转换行为

## 二、核心功能设计

### 1. 剪贴板历史管理

- **自动捕获**：后台监听系统剪贴板变化，自动记录复制内容
- **支持类型**：文本、图片，以及可扩展的结构化内容
- **去重策略**：基于内容哈希去重，重复内容仅刷新时间与使用频次
- **容量管理**：支持最大记录数、保留天数、敏感内容过期时间等配置
- **收藏/保留**：收藏内容长期保留，不受常规清理策略影响

### 2. 智能分类与识别

当前实现采用规则引擎 + 启发式分析，覆盖如下主要类别：

| 类别     | 识别方式                       | 示例                        |
| -------- | ------------------------------ | --------------------------- |
| URL      | 正则匹配 `https?://...`        | 网页链接                    |
| Email    | 正则匹配邮箱格式               | 邮箱地址                    |
| 电话号码 | 电话格式与数字模式识别         | 手机号/座机                 |
| 代码片段 | 关键字、缩进、符号模式综合识别 | Python / JS / SQL           |
| 文件路径 | Unix / Windows 路径模式识别    | `/usr/local/...` / `C:\...` |
| 颜色值   | `#hex`、`rgb()` 等格式识别     | 设计色值                    |
| JSON/XML | 结构化文本解析或模式识别       | API 响应 / 配置片段         |
| 地址     | 多关键词与格式模式匹配         | 收货地址                    |
| 图片     | 剪贴板图像载荷                 | PNG 图片                    |
| 普通文本 | 兜底分类                       | 其他文本                    |

### 3. 快速搜索与检索

- **全文搜索**：基于 SQLite FTS5 提供快速检索能力
- **拼音检索增强**：通过拼音索引支持中文全拼与首字母匹配
- **模糊搜索兜底**：短输入场景通过 LIKE 策略提高召回率
- **按类型过滤**：前端分类筛选器支持按内容类别查看
- **按标签/收藏检索**：结合标签和收藏实现多维度定位

### 4. 快捷操作与内容处理

- **全局唤起**：通过热键快速显示/隐藏主窗口
- **快速粘贴**：选中记录后回填当前使用场景
- **多选模式**：支持进入多选模式，通过复选框选择多条记录
- **批量删除**：一次性删除所有选中条目
- **批量收藏/取消收藏**：批量切换选中条目的收藏状态
- **批量打标签**：通过对话框为选中条目统一添加标签
- **合并复制**：将多条选中的文本内容合并后复制到系统剪贴板
- **全选/反选/清空**：支持全选已加载条目、反转选择状态和清空所有选择
- **内容转换**：内置一键文本转换与格式化能力
- **模板填充**：通过对话框为模板变量赋值后生成最终内容

### 5. 跨设备同步

- **局域网直连**：适用于同一网络内设备间实时同步
- **WebDAV 云同步**：适用于跨网络、多设备长期同步
- **端到端加密**：同步链路与云端存储均采用加密保护
- **冲突解决**：支持自动策略与手动介入结合的冲突处理机制
- **设备隔离与控制**：支持设备配对、移除、开关同步范围

### 6. 安全与隐私

- **敏感内容识别**：自动检测高风险内容并可设置更短过期时间
- **密码锁基线**：启动时自动锁定检查、手动锁定（设置面板 + 托盘菜单）、自动超时锁定
- **唤起拦截**：托盘与全局热键唤起前由 Rust 后端检查锁定状态，锁定时拦截并引导解锁
- **命令保护**：锁定状态下敏感 IPC 命令通过 `require_unlocked()` 守卫拒绝执行
- **前端缓存清理**：锁定时清空前端敏感状态，防止内存残留
- **生物识别解锁**：macOS Touch ID、Windows Hello、Linux 密码回退
- **数据库静态加密**：防止本地数据库文件被直接读取
- **凭据托管**：依赖 OS keyring/credential store 保存关键凭据

- **UI 开发效率高**：Vue 3 + TypeScript + Pinia 适合复杂桌面交互面板开发

## 四、核心数据与模块设计

### 1. 数据模型（逻辑视角）

当前实现仍围绕剪贴板条目、标签、模板、同步设备、冲突日志和安全配置等核心实体组织：

```sql
CREATE TABLE clipboard_entries (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    content       TEXT NOT NULL,
    content_type  TEXT NOT NULL,
    category      TEXT DEFAULT 'text',
    hash          TEXT NOT NULL UNIQUE,
    source_app    TEXT,
    is_favorite   INTEGER DEFAULT 0,
    is_sensitive  INTEGER DEFAULT 0,
    use_count     INTEGER DEFAULT 1,
    created_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at    DATETIME DEFAULT CURRENT_TIMESTAMP,
    expires_at    DATETIME
);

CREATE VIRTUAL TABLE clipboard_fts USING fts5(
    content, category, source_app,
    content='clipboard_entries',
    content_rowid='id'
);

CREATE TABLE tags (
    id    INTEGER PRIMARY KEY AUTOINCREMENT,
    name  TEXT NOT NULL UNIQUE
);

CREATE TABLE entry_tags (
    entry_id  INTEGER REFERENCES clipboard_entries(id),
    tag_id    INTEGER REFERENCES tags(id),
    PRIMARY KEY (entry_id, tag_id)
);
```

在当前版本中，数据库设计已进一步扩展到以下方向：

- 拼音搜索索引字段/索引表
- 模板数据表与占位符元数据
- 局域网配对设备与同步状态记录
- WebDAV 云端设备注册信息与同步元数据
- 同步冲突日志与冲突解决结果
- 安全配置与密钥托管相关状态

- 敏感内容识别
- 规则与模式匹配管理

#### `templates/`

- 模板 CRUD 命令
- `{{placeholder}}` 变量解析
- 模板渲染与最终输出生成

#### `sync/`

- 局域网设备发现（mDNS）
- 配对请求与会话建立
- WebSocket 传输协议
- 加密消息封装与解密

- 锁定/解锁状态机

前端采用 Pinia 按业务域拆分状态：

- `clipboardStore`：历史记录、搜索、过滤、收藏、批量操作
- `templateStore`：模板列表、编辑、填充与应用
- `syncStore`：局域网设备发现、配对和连接状态
- `webdavStore`：云端同步配置、连接状态和手动同步
- `conflictStore`：冲突列表、差异展示、解决动作
- `securityStore`：锁定状态、解锁流程、生物识别能力
- `updaterStore`：更新检查、下载、安装状态

## 五、关键技术实现说明

### 1. 搜索链路

当前搜索能力已经从“基础 FTS5 文本检索”升级为“全文 + 拼音增强”的组合模式：

1. 文本内容写入 SQLite 及 FTS5
2. 中文文本生成拼音全拼与首字母索引
3. 查询时同时尝试：
   - 原文全文匹配
   - 拼音全拼匹配
   - 首字母匹配
   - 短输入 LIKE 回退
4. 将结果统一排序并返回前端展示

该方案兼顾中文检索体验、短查询场景和数据库实现复杂度。

### 2. 同步链路

#### 局域网同步

- 基于 mDNS 发现局域网内其他设备
- 通过配对机制建立可信设备关系
- 使用 WebSocket 建立实时通信
- 通过加密封装同步剪贴板条目
- 做去重、回环防护与状态管理

#### WebDAV 云同步

- 将同步数据组织为云端可管理对象
- 使用独立同步密码做端到端加密
- 支持轮询、增量拉取、手动触发同步
- 使用设备注册表与元数据避免多端混乱
- 基于 ETag/版本信息进行并发与冲突控制

#### 高级冲突处理

- 检测多端同时修改/写入造成的冲突
- 支持可配置的自动解决策略
- 提供冲突日志、差异对比与手动确认 UI
- 尽量保证“可恢复、可解释、可审计”

### 3. 安全控制链路

- 应用启动后自动检测锁定状态，锁定时直接展示解锁界面
- 主窗口、托盘、全局热键均经过 Rust 后端锁定状态保护检查
- 锁定时敏感 IPC 命令通过 `require_unlocked()` 守卫拒绝执行
- 锁定时主动清空前端敏感缓存数据
- 生物识别失败后自动回退密码解锁
- 本地数据库可开启静态加密，减少数据文件泄露风险

### 4. 可测试性设计

项目当前已具备前后端双重验证能力：

- 前端使用 Vitest 做单元测试
- Rust 使用 `cargo test` 覆盖核心逻辑
- 运行时集成测试覆盖锁定/解锁、命令放行与拒绝、唤起拦截、模板保护等关键安全流程
- 工程脚本中内置 `format`、`lint`、`typecheck`、`test:web`、`test:rust` 和 `check` 全量质量门禁

## 九、验证方式

### 1. 功能验证

- 复制不同类型内容，确认监听、入库、分类、展示正确
- 验证搜索、标签、收藏、模板、统计等核心能力可协同工作
- 验证局域网同步、WebDAV 同步与冲突处理流程完整可用

### 2. 安全验证

- 验证锁定态下主窗口、热键、托盘和敏感命令均受保护
- 验证密码解锁、生物识别解锁和失败回退路径
- 验证数据库加密开启后，本地文件不可直接明文读取

### 3. 性能验证

- 在大量历史记录下保持检索流畅
- 后台监听与同步常驻时 CPU / 内存占用稳定
- 图片、模板和搜索增强功能不会显著拖慢主界面响应

### 4. 跨平台验证

- macOS / Windows / Linux 分别验证构建、运行和核心链路
- 验证平台差异能力，如 Touch ID / Windows Hello / Linux 密码回退

### 5. 自动化验证

- 前端执行 `pnpm run test:web`
- Rust 执行 `pnpm run test:rust`
- 类型检查执行 `pnpm run typecheck`
- 全量质量门禁执行 `pnpm run check`

### 6. 发布验证

- 验证更新清单、镜像源、公钥配置与签名校验链路
- 验证安装包升级后的配置迁移与数据兼容性

## 十、设计结论

Smart Clipboard Manager 已不再是单一的“剪贴板历史工具”，而是一个围绕 **高频内容捕获、快速检索、安全保护、多端同步和桌面原生体验** 构建的完整跨平台桌面产品。

从当前代码看，项目已经形成以下清晰产品层次：

1. **基础层**：监听、存储、分类、检索
2. **增强层**：标签、模板、统计、图片、内容转换
3. **协同层**：局域网同步、云同步、冲突处理
4. **安全层**：应用锁、生物识别、数据库加密、命令保护
5. **运维层**：更新器、配置管理、跨平台测试与质量门禁

后续演进重点应从“补齐基础功能”转向“增强扩展性、智能化和平台深度集成”，逐步把剪贴板从工具型能力升级为稳定、可信、可扩展的个人效率中枢。
