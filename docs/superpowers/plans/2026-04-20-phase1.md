# Smart Clipboard Manager -- Phase 1 Implementation Plan

## Context

The Smart Clipboard Manager is a cross-platform desktop app (Tauri 2 + Vue 3 + Rust) that monitors the system clipboard, auto-classifies and stores content, and provides fast search/retrieval. The project currently has only `docs/design.md` and `.gitignore` — no implementation code exists.

**Goal**: Implement Phase 1 (MVP) covering clipboard monitoring, storage, classification, UI, hotkey, tray, and settings.

**Split Strategy**: Phase 1 is split into two sub-phases to keep each implementation session manageable:
- **Phase 1a** (Tasks 1-4): Project scaffold + Backend core
- **Phase 1b** (Tasks 5-8): Frontend + Integration

## Key Architectural Decisions

1. **Mutex<Connection>** for SQLite (adequate for MVP; WAL mode enabled)
2. **spawn_blocking** for arboard (Clipboard is !Send, must stay on one thread)
3. **Event-driven frontend**: Rust emits `clipboard-changed`, Vue listens via `@tauri-apps/api/event`
4. **FTS5 sync via triggers**: INSERT/UPDATE/DELETE triggers keep FTS index in sync
5. **Classification scope**: category describes *dominant nature* of content, not substring matches
6. **Config as JSON file** in app data dir, managed by `ConfigManager` with Mutex
